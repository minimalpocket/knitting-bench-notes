i DSCS

i-DSCS

Apr 10, 20265 min read

The i-DSCS and DSCS use the same option line settings for L9 .

Mechanism

The i-DSCS+DTC is the only ‘active’ yarn sending system on the MACH2X (excluding any additional accessories to the machine). The yarn is gripped between a driving pulley and driven pulley. Based on feedback from the buffer arm angle, the driving pulley spins to send yarn towards the yarn carrier to maintain a stable yarn tension. For example, if the buffer arm angle is low, that suggests that the yarn is tight, so the driving pulley spins to send out more yarn to loosen the tension until the buffer arm returns to a horizontal position.


Source: Page 4 of i-DSCS+DTC Instruction Manual.


Source: Page 11 of i-DSCS+DTC Instruction Manual.

Threading

Thread the yarn through:

  • Top tension equipment.
    • Calibrate tension disk with an 8g weight.
  • i-DSCS.


Source: Page 5 of i-DSCS+DTC Instruction Manual.

To make it easier to pull the yarn through, use Manual Machine Operation > Yarn Sending ON.

Yarn considerations

Do not:

  • Feed the set-up yarn and draw thread.
  • Use the yarn sending device (i.e., side roller) and side tension arm.
  • Feed 3 or more yarns through the i-DSCS because the large number of yarns may drop out of the pulley.
    • 3rd yarn should skip the i-DSCS and use the yarn sending device (i.e., side roller) and side tension arm instead.

Based on personal experience, yarns with high bending stiffness (e.g., thick monofilaments) may not ‘flow’ through the buffer arm smoothly. I tried threading 0.3mm nylon monofilament through the i-DSCS and when the yarn was tight, the driving pulley spun to send yarn, but because the yarn didn’t move through the eyelet of the buffer arm, the buffer arm angle didn’t change so that driving pulley ended up sending a massive tangle of yarn.

Dynamic Tension Control (DTC)

DTC changes the tension of the buffer arm depending on the yarn sending speed.

Weak/Medium/Strong/etc. are presets with default values for the buffer arm tension (unit: gf) for different speeds. If necessary, the buffer arm tension can be changed manually.

  • Maximum: 40gf
  • Minimum: 3gf
  • Cannot input: 1-2gf
  • 0gf means that the i-DSCS is not being used

The example below shows that the buffer arm tension is set to a higher force at a low knitting speed.


Source: Page 39 of i-DSCS+DTC Instruction Manual.

The only time I have seen the buffer arm tension being adjusted is during training in Wakayama, when the plating was not stable. In the end, a trainer found that setting the main yarn to a very high tension and the plating yarn to a very low tension made the plating more stable (but it still wasn’t perfect).

Troubleshooting

  • Yarn Error.
    • Check if the threading is ok, e.g., if the yarn slipped out from the driving/driven pulleys or if the yarn is stuck somewhere.
    • Check if there is yarn breakage at the needle bed.
    • Check if your pattern has a lot of variation in yarn length between courses.
    • Check if the yarn is so thin that is is slipping between the driving/driven pulleys. If yes, try changing the textured rubber to a smooth rubber to improve contact between the yarn and the pulleys.
  • Yarn breakage detected by buffer arm.
    • Check if the yarn broke.
    • If there seems to be no issue with the yarn, check if the buffer arm angle tends to be on the high side. If yes, try increasing the i-DSCS force (e.g., from W to M).
      • With elastic yarn, sometimes I find that W mode works better than ELA. YARN mode. ELA. YARN mode seemed to make the yarn tension too weak.
