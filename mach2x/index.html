MACH2X for Shima Seiki Shaping Machine Users

MACH2X for Shima Seiki Shaping Machine Users

Apr 16, 20262 min read

These are (informal) notes about the Shima Seiki MACH2X M173X15L knitting machine (15 gauge, large hook needles, 1.7m wide needle bed). The notes assume that the reader is familiar with Shima Seiki shaping machines and the Package Base Pattern → Compressed Pattern → Developed Pattern workflow.

You’ll get more accurate information from the Shima Seiki manuals 1 and help files. So, the purpose of these notes is to (1) highlight concepts and settings that I find more relevant when using the MACH2X, (2) explain the concepts in the way that I understand them, (3) include tips from my experience with the machines, and (4) record things that I keep on forgetting.
